# Anti-Slop UI Audit Report

> **Project**: ZChat Web Frontend Client (`BackendChatApp`)  
> **Date**: 2026-10-09  
> **Audit File**: `anti-slop/audit-001-2026-10-09.md`  
> **Design Guidance**: `DESIGN.md` (ENERGY: 2 | RHYTHM: 2 | MOTION: 1)  
> **Filter Standard**: Antislop Core Filter (R-01 through R-38)

---

## Executive Summary

Audit dilaporkan untuk antarmuka frontend ZChat Web Client. Secara umum, struktur desain sudah mengikuti `DESIGN.md` dengan skema warna Zinc/Slate yang rapi dan bebas dari pernak-pernik AI slop berlebihan (seperti mesh gradients, neon glow liar, atau hero sections templat). 

Namun, ditemukan beberapa masalah pada tingkat **Hard Gate (Aksesibilitas, Kontras, Keyboard, dan Mobile Tap Targets)** yang perlu diperbaiki agar aplikasi memenuhi standar antislop dan WCAG AA.

## Audit Detail & Recommended Action Items

### Finding #1 [HIGH]: Modal Keyboard Control & Focus Trap
- **Aturan**: R-32 (Keyboard Accessibility) & R-26 (Interactive Elements)
- **Masalah**: Modal Auth, Tambah Teman, dan Info Kontak tidak menangkap tombol `Escape` keyboard dan tidak membatasi urutan `Tab` agar tetap di dalam modal.
- **Rekomendasi Perbaikan**: Tambahkan event listener global `keydown` untuk tombol `Escape` di `app.js` dan pastikan elemen pertama di dalam modal langsung mendapatkan fokus saat modal terbuka.

### Finding #2 [HIGH]: Color Contrast Ratio
- **Aturan**: R-25 (Color Contrast WCAG AA)
- **Masalah**: `--text-muted: #71717a` pada latar belakang `#27272a` (bubble pesan) memiliki rasio kontras 3.0:1 (di bawah ambang batas WCAG AA 4.5:1).
- **Rekomendasi Perbaikan**: Tingkatkan kontras warna teks metadata pesan ke `#a1a1aa` atau `#cbd5e1` (rasio kontras > 5.5:1).

### Finding #3 [HIGH]: Mobile Tap Target Sizes
- **Aturan**: R-03 (Mobile Responsiveness)
- **Masalah**: Area klik tombol `.tab-btn` pada tampilan layar HP hanya ~34px, menyulitkan pengguna layar sentuh (minimal 44px).
- **Rekomendasi Perbaikan**: Perbesar padding dan tinggi minimal tombol tab dan tombol ikon pada breakpoints mobile (`@media (max-width: 768px)`).

### Finding #4 [HIGH]: Click Outside & Dropdown Closing
- **Aturan**: R-26 (Interactive Elements)
- **Masalah**: Dropdown menu header obrolan tidak menutup secara otomatis saat pengguna mengeklik area di luar menu.
- **Rekomendasi Perbaikan**: Tambahkan handler `document.addEventListener('click')` untuk menutup dropdown jika pengguna mengeklik di luar `#chatDropdownMenu` atau `#btnChatMenu`.

### Finding #5 [HIGH]: Focus Ring Textarea
- **Aturan**: R-32 (Keyboard Accessibility)
- **Masalah**: `.chat-textarea` memiliki properti `outline: none;` tanpa pengganti `:focus-visible` langsung.
- **Rekomendasi Perbaikan**: Berikan indikator fokus yang jelas pada form container `:focus-within` atau langsung pada textarea.

### Finding #6 [MEDIUM]: UI Loading States
- **Aturan**: R-27 (UI States - Loading)
- **Masalah**: Tidak ada umpan balik visual saat memproses login/register atau saat mengambil percakapan dari API.
- **Rekomendasi Perbaikan**: Tambahkan state tombol `disabled` + teks "Memproses..." saat submit form, dan skeleton shimmer sederhana pada container pesan saat memuat data.

### Finding #7 [MEDIUM]: Micro-Interaction Consistency
- **Aturan**: R-19 (Animations) & MOTION: 1
- **Masalah**: Kemunculan modal terasa kaku tanpa transisi skala/opasitas mikro.
- **Rekomendasi Perbaikan**: Tambahkan `transform: scale(0.98)` ke `scale(1)` dengan `opacity` 0.15s pada `.modal-card.active`.

### Finding #8 [MEDIUM]: Active Chat Sidebar Indicator
- **Aturan**: R-14 (Feature Cards & List Items)
- **Masalah**: Percakapan yang sedang dibuka di sidebar kurang begitu kontras dibanding percakapan lainnya.
- **Rekomendasi Perbaikan**: Berikan garis aksen biru `border-left: 3px solid var(--accent-primary)` pada `.list-item.active`.

## Resolution & Follow-Up Report (Status: RESOLVED)

Semua temuan audit (#1 hingga #10) telah diperbaiki dan diverifikasi sesuai dengan aturan Antislop & Antislop-UI:

| # | Rule Code | Status | Verification & Resolution Details |
|---|---|---|---|
| **1** | R-32, R-26 | **FIXED** | Menambahkan global keyboard listener untuk tombol `Escape` (menutup dropdown, modal contact info, modal add friend, dan membatalkan edit pesan). Menerapkan accessible focus trap pada modal aktif saat navigasi tombol `Tab` / `Shift+Tab`. |
| **2** | R-25 | **FIXED** | Memperbaiki kontras teks metadata: `--text-muted` diperbarui ke `#94a3b8` (>4.5:1), dan secara eksplisit memberikan warna `#cbd5e1` pada `.message-row.other .message-meta` dan `#bfdbfe` pada `.message-row.me .message-meta` (>5.5:1 rasio kontras WCAG AA). |
| **3** | R-03 | **FIXED** | Memastikan area sentuh minimum 44px (`min-height: 44px`) pada `.tab-btn`, `.btn-icon`, `.chat-back-btn`, dan `.btn-action-primary` pada media query layar mobile (`@media (max-width: 768px)`). |
| **4** | R-26 | **FIXED** | Memperbarui listener click luar dokumen sehingga dropdown `#chatDropdownMenu` otomatis tertutup bila pengguna mengeklik di luar menu atau tombol pemicu. |
| **5** | R-32 | **FIXED** | Menambahkan `:focus-visible` dengan outline 2px jelas (`--border-focus`) pada `.chat-textarea` dan box shadow ring pada `.chat-input-form:focus-within`. |
| **6** | R-27 | **FIXED** | Menambahkan indikator visual `.btn-spinner` animasi CSS pada tombol submit saat proses login, register, dan verifikasi OTP, serta skeleton shimmer (`#chatLoadingSkeleton`) saat memuat percakapan. |
| **7** | R-19 | **FIXED** | Menerapkan mikro-animasi halus (`transform: scale(0.96) -> scale(1)` dan transisi opacity 0.15s cubic-bezier) pada `.modal-card` ketika `.modal-overlay.active`. |
| **8** | R-14 | **FIXED** | Menambahkan visual hierarchy accent `border-left: 3px solid var(--accent-primary)` pada `.list-item.active` di daftar sidebar. |
| **9** | R-06 | **FIXED** | Menaikkan ukuran font metadata timestamp dari `0.6875rem` (11px) ke standar yang nyaman dibaca `0.75rem` (12px) dengan font-weight 500. |
| **10** | R-31 | **FIXED** | Menyelaraskan seluruh dokumentasi token CSS di `:root` dengan spesifikasi `DESIGN.md`. |
